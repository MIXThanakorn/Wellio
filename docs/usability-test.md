# ลองใช้ Wellio กับคนที่ไม่ถนัดเทคโนโลยี

สถานะ: เตรียมชุดทดสอบแล้ว ยังไม่มีผลจากผู้ทดลองจริง อย่านับผลอัตโนมัติเป็นผลจากคน

ใช้ผู้ทดลอง 3–5 คน ครั้งละประมาณ 10–15 นาที บนมือถือที่เขาใช้จริง เริ่มจากลิงก์เว็บที่ deploy แล้วและเลือก “สำรวจแอปด้วยข้อมูลตัวอย่าง” เพื่อไม่กระทบบันทึกจริง ไม่ต้องใช้อีเมลหรือรหัสผ่าน

อ่านเป้าหมายด้านล่างทีละข้อ อย่าบอกว่าปุ่มอยู่ตรงไหน ขอให้ผู้ทดลองพูดสิ่งที่คิด หากติดเกิน 60 วินาทีให้บันทึกจุดที่ติดก่อนช่วย หยุดได้ทุกเมื่อ ไม่ต้องบันทึกเสียงหรือข้อมูลส่วนตัว

หลังลอง ถามเพียง 3 ข้อ: “ตรงไหนเข้าใจยากที่สุด”, “มีคำหรือสัญลักษณ์ใดที่ไม่เข้าใจ”, “ถ้าให้ใช้พรุ่งนี้เอง มั่นใจแค่ไหน 1–5” จดคำพูดจริง ไม่ตีความแทน

เกณฑ์ก่อนเผยแพร่: งานอาหาร/น้ำ/กิจกรรมสำเร็จเองอย่างน้อย 80% ของผู้ทดลอง (เช่น 4 ใน 5 คน) ไม่มีข้อมูลหายหรือบันทึกผิดคน ไม่มีการนับบันทึกซ้ำ และงานหลักแต่ละงานใช้ไม่เกิน 60 วินาที หากยังไม่ผ่านให้แก้สาเหตุที่คนติดซ้ำแล้วทดสอบอีกรอบ

ตรวจ iPhone/Safari และ Android/Chrome อย่างน้อยอย่างละหนึ่งเครื่องด้วย โดยเฉพาะกล้อง รูป HEIC การกลับจากกล้อง ปุ่มบันทึกขณะคีย์บอร์ดเปิด และการสลับแอป การจำลองขนาดหน้าจอไม่ยืนยันว่ากล้องของเครื่องจริงทำงาน

ส่งผลกลับมาเป็นตารางนี้โดยไม่ต้องระบุชื่อจริงหรือแนบรูปอาหารส่วนตัวได้ แล้วจึงสรุปสิ่งที่พบและปรับหน้าจอจากผลจริง
